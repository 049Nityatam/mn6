ขั้นตอนการนำขึ้น GitHub Pages

วิธีเปิดใช้งานเว็บไซต์ Portfolio ออนไลน์ฟรีด้วย GitHub

ข้อแนะนำ: ตั้งชื่อไฟล์หลักนี้ว่า index.html และนำรูปภาพ profile.jpg วางไว้ใน Folder เดียวกัน
  1. สร้าง Repository ใหม่บน GitHub: เข้าไปที่ github.com/new ตั้งชื่อคลังไฟล์ เช่น my-portfolio
  2. อัปโหลดไฟล์ (Upload Files): กดที่ปุ่ม Upload an existing file แล้วลากไฟล์ index.html และ profile.jpg ขึ้นไป จากนั้นกด Commit changes
  3. เปิดใช้งาน GitHub Pages:
    • ไปที่เมนู Settings ของ Repository
    • เลือกแถบเมนูด้านข้าง Pages
    • ใต้หัวข้อ Build and deployment -> เลือก Source เป็น Deploy from a branch
    • เลือก Branch เป็น main (หรือ master) แล้วกด Save
  4. เข้าชมเว็บไซต์: รอระบบประมวลผลประมาณ 1-2 นาที เว็บไซต์ของคุณจะออนไลน์ได้ที่ลิงก์ https://your-username.github.io/my-portfolio/
